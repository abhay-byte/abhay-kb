# CSES Problem Set

**Source:** [cses.fi/problemset](https://cses.fi/problemset/)
**Total Problems:** 300+

The CSES Problem Set is a collection of algorithmic programming problems maintained by the University of Helsinki. It covers a wide range of topics in competitive programming.

## Additional Topics (50+)

- **Range Queries** — Segment trees, Fenwick trees, Sparse tables
- **Geometry** — Convex hull, line intersections, polygon area
- **Advanced Techniques** — Meet in the middle, Heavy-Light decomposition
- **Additional Graph Algorithms** — Maximum flow, min cut, matching
