Hi, I'm @abhay-byte — Agentic Wizard

I'm an Agentic Wizard — I don't just write code, I build the systems that let AI agents write it with me.

My daily workflow is fully agentic. Claude Code, Codex CLI, Gemini CLI, Qwen, Aider, and a rotating cast of AI tools run side by side, each handling what it does best. To orchestrate all of this, I built Nexus Terminal — a multi-agent terminal workspace where multiple AI agents collaborate in parallel, because no existing tool gave me the control and flexibility I needed, so I built my own.

Beyond the terminal, I work extensively with MCP servers to extend what agents can actually do — giving them real tools, real context, and real capabilities beyond just generating text. AI IDEs like Cursor and Windsurf are part of the stack too, used where they genuinely add leverage.

I also run a fleet of specialized bots that keep everything current automatically — periodically updating my knowledge base, resume, documentation, and other content without me having to touch it manually. The whole system runs on Android through Flux Linux, meaning this entire agentic infrastructure lives in my pocket. A full Linux environment, multiple AI agents, continuous background updates — all from a phone.

This knowledge base is part of that same philosophy. It's structured to be useful for both humans and AI — clean enough to read, organized enough to index, and precise enough to serve as context for agents that need to reason about software engineering, system design, and architecture without hallucinating the basics.

Everything I build is open source — all code, all assets, no paywalls, no courses, no gatekeeping. Just FOSS, built in the open, for anyone who wants to use it, fork it, or build on top of it.
