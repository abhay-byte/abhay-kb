# GitHub Copilot in Visual Studio — May Update: Plan Agent and Skills Panel
> Originally published on GitHub Blog — June 4, 2026

![Cover](https://placehold.co/800x400/1a1a2e/00d4ff?text=GitHub+Copilot+VS+May+Update)

## Summary

GitHub shipped significant updates for Copilot in Visual Studio 2026, headlined by the new Plan agent that lets developers collaborate with Copilot on implementation plans before writing any code. The Plan agent explores the codebase with read-only tools, asks clarifying questions, and drafts detailed plans saved as markdown files — ready to hand off to Agent mode with a single click.

Other key features include a new Skills panel for managing agent skills from workspace and user profile, multi-file summary diff views for reviewing Copilot changes with per-file or per-chunk accept/undo controls, and a context window usage indicator with conversation summarization to compact earlier turns and free up space.
