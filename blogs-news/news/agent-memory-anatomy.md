A deep technical analysis of AI agent memory systems, deconstructing them into three core components: extractors (what to remember), stores (vector, relational, or graph), and retrievers (how to recall). The article critiques how most agent memory libraries borrow cognitive science terminology like "episodic" and "semantic" without fully implementing the underlying architectural distinctions.
