# Mozilla Says 271 Vulnerabilities Found by Mythos Have 'Almost No False Positives'

> Originally published on Ars Technica — May 14, 2026

![Cover](https://placehold.co/800x400/1a1a2e/00d4ff?text=Mozilla+Mythos+AI+Security)

## Summary

Mozilla provided an in-depth look at how Anthropic's Mythos AI model, combined with a custom agent harness, identified 271 security vulnerabilities in Firefox over two months — with almost no false positives. Unlike earlier AI-assisted vulnerability scanning that produced hallucinated bug reports, Mozilla's custom harness guided Mythos through project-specific code analysis, delivering actionable results. Mozilla's CTO previously declared that such AI-assisted detection means "zero-days are numbered."
