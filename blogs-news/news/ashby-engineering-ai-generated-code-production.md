# Ashby Engineering: >50% AI-Generated Code in Production, Zero Regressions

> Originally published on Ashby Engineering Blog — June 04, 2026

![Cover](https://placehold.co/800x400/1a1a2e/00d4ff?text=AI+Code+in+Production)

## Summary

Since August 2025, more than half of all new code hitting Ashby's production systems has been AI-generated — yet customer issues remain broadly stable with zero regressions in code quality, velocity, or onboarding time. Colin from Ashby Engineering shares the company's thesis that "the cost of producing code is heading towards zero," and engineers' real value lies in judgment, taste, and customer understanding — not syntax and keystrokes. The post emphasizes that empathy cannot be replaced by AI and engineers remain responsible for what they ship.
