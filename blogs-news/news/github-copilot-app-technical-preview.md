# GitHub Copilot App Now Available in Technical Preview
> Originally published on GitHub Blog — May 14, 2026
![Cover](https://placehold.co/800x400/1a1a2e/00d4ff?text=GitHub+Copilot+App)

## Summary
GitHub released the Copilot App in technical preview — a native desktop experience built for agentic development. It runs parallel agent sessions with isolated git worktrees, branches, and task state, allowing developers to start from an issue or PR and go through to merge within a single application.

## Key Points
- The app runs agent sessions in isolated parallel workstreams with their own git worktrees and branches
- Supports three session modes: autonomous agents, guided coding, and review-assisted workflows
- Includes "Agent Merge" for landing changes through pull request review directly from the desktop client
