# I Turned a $80 RK3562 Android Tablet Into a Debian Linux Workstation

> Originally published on GitHub — May 17, 2026

![Cover](https://placehold.co/800x400/1a1a2e/00d4ff?text=RK3562+Debian+Tablet)

## Summary

A developer documented the complete process of transforming a cheap $80 Doogee U10 Android tablet (powered by the Rockchip RK3562 SoC) into a fully functional Debian 12 Bookworm Linux workstation. The project, hosted on GitHub as `rk3562deb`, provides a build system that produces flashable Debian images with working GPU acceleration, Wi-Fi, and even NPU-driven local LLM inference (Qwen3-0.6B at ~4.9 tok/s on-device).
