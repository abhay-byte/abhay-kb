# Google Workspace CLI: Unified Command-Line Tool Built for Humans and AI Agents

> Originally published on InfoQ — June 2, 2026

![Cover](https://placehold.co/800x400/1a1a2e/00d4ff?text=Google+Workspace+CLI)

## Summary

Google released a new open-source CLI for Google Workspace, written in Rust, providing a unified interface to Drive, Gmail, Calendar, Sheets, and 100+ other APIs. Unlike traditional CLIs with static command lists, `gws` reads Google's Discovery Service at runtime to build its command surface dynamically, automatically picking up new endpoints without updates. It ships with over 100 bundled agent skills and an MCP server option for connecting to Claude Code and Gemini CLI, though early community feedback is mixed due to complex OAuth setup.
