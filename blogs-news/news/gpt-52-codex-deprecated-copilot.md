# GPT-5.2 and GPT-5.2-Codex Deprecated in GitHub Copilot

> Originally published on GitHub Blog — June 5, 2026

![Cover](https://placehold.co/800x400/1a1a2e/00d4ff?text=GPT-5.2+Deprecated+Copilot)

## Summary

As of June 5, 2026, GitHub has deprecated GPT-5.2 and GPT-5.2-Codex across most Copilot experiences including Copilot Chat, inline edits, ask and agent modes, and code completions. Users are being migrated to GPT-5.5 as the suggested alternative, while GPT-5.2 remains available only in Copilot Code Review. Enterprise administrators may need to manually enable access to the replacement models through their Copilot organization policies. The deprecation follows the June 1 transition to usage-based billing for all Copilot plans.
