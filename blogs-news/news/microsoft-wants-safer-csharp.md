# Microsoft Wants Safer C# Without Turning It Into Rust

> Originally published on The Register — May 26, 2026

![Cover](https://placehold.co/800x400/1a1a2e/00d4ff?text=Safer%20C%23%20Without%20Rust)

## Summary

Microsoft is planning significant memory safety improvements for C# starting with version 16, introducing a new safety model that makes unsafe code more visible and easier to review. The changes include redefining the unsafe keyword so it propagates to callers, limiting unsafe to method-level scope, and adding NuGet package safety badges — all without giving up automatic memory management or turning C# into Rust.
