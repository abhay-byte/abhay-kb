# ReactOS Achieves 3D-Accelerated Half-Life on Real Hardware After 28 Years of Development

> Originally published on Phoronix — June 13, 2026

![Cover](https://placehold.co/800x400/1a1a2e/00d4ff?text=ReactOS+Half-Life+3D)

## Summary

ReactOS, the 28-year-old open-source operating system aiming for binary compatibility with Windows software, has achieved a major milestone: running Half-Life with full 3D acceleration on real hardware (a Dell OptiPlex with Core i5 2400 and NVIDIA GeForce 8400GS). While Half-Life already runs well on Linux via Wine, this marks a significant validation of ReactOS's Windows binary compatibility mission and demonstrates the project's continued progress.
