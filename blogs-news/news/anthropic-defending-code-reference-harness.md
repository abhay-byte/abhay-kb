# Anthropic Open-Sources Framework for AI-Powered Vulnerability Discovery

> Originally published on GitHub / Anthropic — June 04, 2026

![Cover](https://placehold.co/800x400/1a1a2e/00d4ff?text=AI+Vulnerability+Discovery)

## Summary

Anthropic released an open-source reference implementation for autonomous vulnerability discovery and remediation with Claude, based on learnings from Project Glasswing partnerships. The repo includes Claude Code skills for threat modeling, scanning, triage, and patching, plus an autonomous scanning harness configured for C/C++ memory vulnerabilities using Docker and ASAN. It also supports a managed option via Claude Security for production use.
