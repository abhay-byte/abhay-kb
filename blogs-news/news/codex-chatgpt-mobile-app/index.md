# Codex Is Now in the ChatGPT Mobile App

> Originally published on OpenAI — May 14, 2026

![Cover](https://placehold.co/800x400/1a1a2e/00d4ff?text=Codex+on+ChatGPT+Mobile)

## Summary

OpenAI has expanded Codex, its AI-powered coding agent, to the ChatGPT mobile app on both iOS and Android. Developers can now monitor, steer, and approve coding tasks in real time across devices and remote environments. This marks the first time OpenAI has released Codex beyond desktop access, making AI-assisted development available from anywhere.
