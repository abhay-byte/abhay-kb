> Originally published on InfoQ — May 2026

![Cover](https://placehold.co/800x400/1a1a2e/00d4ff?text=AWS%20MCP%20Server%20GA)

## Summary

AWS made its managed Model Context Protocol (MCP) server generally available, giving AI coding agents controlled access to all AWS APIs, documentation, and operational workflows through a standard interface. The server provides IAM-based access controls, CloudWatch metrics, CloudTrail logging, and sandboxed Python execution — enabling organizations to govern and audit agent activity without handing over broad credentials.
