# Seven new stable Linux kernels patch CVE-2026-46333

> Originally published on LWN.net — May 2026

![Cover](https://placehold.co/800x400/1a1a2e/00d4ff?text=Linux+Kernel+Security+Patch)

## Summary

Greg Kroah-Hartman announced the release of seven new stable Linux kernels — including 7.0.8, 6.18.31, 6.12.89, and others — containing patches for CVE-2026-46333, a vulnerability reported by the Qualys Security Advisory team. A proof-of-concept exploit has already been published, making patching urgent for production systems.

## Key Points

- CVE-2026-46333 is a kernel vulnerability with a published PoC exploit
- Patches shipped across seven stable kernel branches including 7.0.x, 6.18.x, 6.12.x, and LTS branches
- Jann Horn had proposed a patch as early as 2020, highlighting long-tail vulnerability discovery
