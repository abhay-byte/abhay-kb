# Microsoft Ports TypeScript Compiler to Go, Promising 10x Speed Boost

> Originally published on The New Stack — May 2026

![Cover](https://placehold.co/800x400/1a1a2e/00d4ff?text=TypeScript+Go+Compiler)

## Summary

Microsoft's Anders Hejlsberg announced the TypeScript compiler is being ported to Go, delivering a claimed 10x increase in compile speed. The team chose Go over Rust and C# for its native code compilation, garbage collection, and excellent control over memory and data layout. The move has sparked significant discussion in the developer community about language choices for infrastructure-level tooling, with Rust's safety guarantees weighed against Go's simplicity and faster development cycles.
