# Go: Support for Generic Methods Proposed
> Originally published on GitHub (golang/go) — May 27, 2026

![Cover](https://placehold.co/800x400/1a1a2e/00d4ff?text=Go+Generic+Methods)

## Summary
A new proposal has been filed on the Go issue tracker to add generic methods support to the language, potentially allowing methods on types to have their own type parameters independent of their receiver type. Currently Go only supports generic functions and generic types, but not methods with their own type parameters. The proposal has garnered significant community attention with 165 points on Hacker News, sparking debate on language complexity versus expressiveness.
