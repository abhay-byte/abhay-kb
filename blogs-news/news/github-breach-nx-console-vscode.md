# GitHub Confirms Breach via Malicious Nx Console VS Code Extension
> Originally published on The Hacker News — May 21, 2026

![Cover](https://placehold.co/800x400/1a1a2e/00d4ff?text=GitHub+Breach+Nx+Console)

## Summary
GitHub confirmed that its internal repositories were breached after an employee's device was compromised through a trojanized version of the Nx Console VS Code extension. The malicious extension, available on the VS Code Marketplace for only 18 minutes on May 18, 2026, led to the exfiltration of approximately 3,800 internal code repositories by the threat group TeamPCP.
