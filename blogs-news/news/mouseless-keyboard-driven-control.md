## Summary

Mouseless is a new cross-platform tool that enables full keyboard-driven control of macOS, Linux, and Windows desktops. The tool lets users control their computer entirely without a mouse or trackpad, using keyboard shortcuts and navigation for all interactions. It reached the top spot on Hacker News with 430 points and 179 comments, indicating strong developer interest in keyboard-centric workflows.

The project addresses a common desire among developers and power users to minimize hand movement between keyboard and mouse, following in the tradition of tools like Vimium, Tmux, and tiling window managers. The massive HN response suggests there's a significant underserved market for seamless keyboard-only desktop navigation.
