# Linus Torvalds: AI bug hunters have made Linux security list 'almost entirely unmanageable'
> Originally published on The Register — May 18, 2026

![Cover](https://placehold.co/800x400/1a1a2e/00d4ff?text=Linux+AI+Bug+Reports+Crisis)

## Summary

Linus Torvalds declared the Linux kernel security mailing list has become "almost entirely unmanageable" due to multiple researchers using AI tools to find the same bugs and filing duplicate reports. In his weekly kernel status post for Linux 7.1 release candidate four, Torvalds urged that "AI detected bugs are pretty much by definition not secret" and that treating them on private lists only worsens duplication. He appealed to researchers to "read the documentation, create a patch too, and add some real value on top of what the AI did," contrasting with Greg Kroah-Hartman's recent positive remarks about AI as a useful tool for FOSS.
