# Grit: Rewriting Git in Rust with AI Agents

> Originally published on GitButler Blog — June 9, 2026

![Cover](https://placehold.co/800x400/1a1a2e/00d4ff?text=Grit+Git+Rewritten+In+Rust)

## Summary

Scott Chacon (co-founder of GitHub, creator of GitButler) used Anthropic-style agent swarms to rewrite Git from scratch in Rust as a library-based, memory-safe implementation called Grit. The project passes over 99% of Git's entire 42,000+ test suite, taking a few months and billions of tokens worth of agent work. Grit is designed as a reentrant, linkable Rust library rather than the traditional Unix-style collection of chained commands, potentially enabling new use cases that the C Git implementation struggles with.
