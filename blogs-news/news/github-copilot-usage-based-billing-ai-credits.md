# GitHub Copilot Moves to Usage-Based Billing with AI Credits Starting June 1

> Originally published on GitHub Blog — April 27, 2026

![Cover](https://placehold.co/800x400/1a1a2e/00d4ff?text=GitHub+Copilot+Billing)

## Summary

GitHub announced that all Copilot plans will transition to usage-based billing on June 1, 2026, replacing the current premium request unit (PRU) system with GitHub AI Credits. Usage will be calculated based on token consumption (input, output, and cached tokens) at API rates per model. This aligns Copilot pricing with actual compute usage as it evolves from a code completion tool into an agentic platform capable of running multi-hour autonomous coding sessions.
