# Microsoft Coreutils for Windows: UNIX Utilities Go Native

> Originally published on Hacker News — June 2, 2026

![Cover](https://placehold.co/800x400/1a1a2e/00d4ff?text=Coreutils+for+Windows)

## Summary

Microsoft released Coreutils for Windows, a native port of uutils/coreutils, findutils, and grep packaged as a single multi-call binary for Windows. The tool provides familiar UNIX commands like `ls`, `cat`, `cp`, `grep`, and `find` that work identically across Linux, macOS, WSL, and now native Windows. Available via WinGet (`winget install Microsoft.Coreutils`), the project is in preview and requires PowerShell 7.4+, scoring 192 points on Hacker News.
