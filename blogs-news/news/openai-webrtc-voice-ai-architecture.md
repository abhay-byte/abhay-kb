# OpenAI Outlines WebRTC Architecture for Low-Latency Voice AI at Scale

> Originally published on InfoQ — May 2026

![Cover](https://placehold.co/800x400/1a1a2e/00d4ff?text=OpenAI%20WebRTC%20Voice%20AI)

## Summary

OpenAI detailed how it adapted WebRTC for global-scale low-latency voice AI, replacing a conventional media termination model with a relay-transceiver architecture. The design keeps WebRTC session state in a dedicated transceiver layer while using lightweight relays to reduce public UDP exposure and keep media routing close to users — optimized for predominantly 1:1 model-to-user sessions rather than multi-party conferencing.
