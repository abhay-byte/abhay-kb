# Claude Code Adds Dynamic Workflows for Parallel Agent Coordination

> Originally published on InfoQ — June 2, 2026

![Cover](https://placehold.co/800x400/1a1a2e/00d4ff?text=Claude+Code+Dynamic+Workflows)

## Summary

Anthropic introduced Dynamic Workflows for Claude Code, a research preview feature that handles complex software engineering tasks by coordinating large numbers of AI agents within a single workflow. Instead of relying on manually configured agent teams, Claude dynamically generates orchestration scripts, breaks work into subtasks, runs them in parallel across specialized agents, and validates results before presenting a final answer. An "ultracode" setting allows Claude to autonomously decide when a workflow-based approach is appropriate.
