Since JavaOne 2025, Java has moved from JDK 25 (the latest LTS) toward JDK 26 with major updates across the language, APIs, runtime, tooling, security, startup performance, and garbage collection. JDK 26 preview features include primitive patterns, lazy constants, structured concurrency, PEM encoding, HTTP/3 support, and new deep-reflection options — continuing Java's rapid release cadence with significant quality-of-life improvements for developers.
