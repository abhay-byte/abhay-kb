# macOS 27 Beta Breaks Asahi Linux Boot on Apple Silicon

> Originally published on Phoronix — June 12, 2026

![Cover](https://placehold.co/800x400/1a1a2e/ff8800?text=macOS+27+Breaks+Asahi+Linux)

## Summary

Apple's macOS 27 "Golden Gate" beta, released this week at WWDC, changes the boot picker and Startup Disk handling, making Asahi Linux partitions invisible and unbootable. Asahi Linux has filed a bug report with Apple and is warning users to avoid upgrading to macOS 27 beta, though existing Linux partitions remain intact and data is not lost.

## Key Details

- macOS 27 beta changes the boot picker — Asahi Linux partitions are no longer visible.
- Existing partitions remain present without data loss but cannot be booted.
- Users with a secondary macOS 26 installation can still boot their Asahi partition.
- Asahi Linux filed a bug report and is warning users to avoid macOS 27.
- Linux 7.2 was also announced this week to enable boot support for Apple M3 devices.
