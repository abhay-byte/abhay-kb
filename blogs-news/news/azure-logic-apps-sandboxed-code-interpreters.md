# Azure Logic Apps Adds Sandboxed Code Interpreters to Agent Workflows
> Originally published on InfoQ — May 27, 2026

![Cover](https://placehold.co/800x400/1a1a2e/00d4ff?text=Azure+Logic+Apps+Agents)

## Summary
Microsoft added sandboxed code interpreters to Azure Logic Apps, enabling agents within integration workflows to generate and execute Python, JavaScript, C#, and PowerShell code in Hyper-V isolated sessions. Architects get full control over model selection per workflow. The capability positions Logic Apps as an agent platform for integration alongside Microsoft's Foundry and Copilot Studio offerings, extending low-code integration with AI-powered code execution.
