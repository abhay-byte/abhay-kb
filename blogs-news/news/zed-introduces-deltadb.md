# Zed Introduces DeltaDB: Version Control Built Between Commits

> Originally published on Zed Blog — June 12, 2026

![Cover](https://placehold.co/800x400/1a1a2e/00aaff?text=Zed+DeltaDB)

## Summary

Zed announced DeltaDB, a new kind of version control system that captures every fine-grained operation (not just commits) alongside the conversation that drove it. Built to address the gap between human-agent collaboration and Git's snapshot-based model, DeltaDB gives each editing operation a stable identity and records messages alongside the edits they produced — a single coherent abstraction for the stream of collaborative work.

## Key Details

- **Fine-grained deltas:** Every operation gets a stable identity — not just every commit but every edit in between.
- **Conversation-aware:** Messages and the edits they produce are recorded side by side, preventing drift.
- **Beta ready:** A beta version is available in a few weeks; Zed has backing from Sequoia.
- **Agent-native:** Designed for the era of AI-assisted coding where the conversation generating code is the true source of software.
- Addresses the problem that Git was never designed for continuous collaboration between humans and AI agents.
