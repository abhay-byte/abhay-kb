# yt-dlp Deprecates Bun Support, Citing 'Vibe-Coded' Rust Rewrite

> Originally published on GitHub (yt-dlp) — May 22, 2026

![Cover](https://placehold.co/800x400/1a1a2e/00d4ff?text=yt-dlp+Deprecates+Bun)

## Summary

The popular yt-dlp project announced it is limiting and deprecating support for Bun as a JavaScript runtime due to compatibility and security concerns. The announcement specifically calls out that Bun was recently rewritten in Rust using Claude AI, and its development "seems to have taken a turn towards being fully vibe-coded" — a notable criticism from the open-source community. Only Bun versions 1.2.11 through 1.3.14 (the last built from the original Zig codebase) will continue to be supported.

## Why This Matters

This is a high-profile example of the open-source community pushing back against AI-generated code quality concerns. yt-dlp's decision highlights growing unease with AI-assisted rewrites of critical infrastructure and the maintenance burden they create for downstream projects.
