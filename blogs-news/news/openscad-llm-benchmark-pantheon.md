## Summary

ModelRift ran a practical benchmark challenging AI coding tools to generate parametric OpenSCAD code for the Pantheon in Rome. The test evaluates how well LLMs handle spatial geometry, radial symmetry, and constructive solid geometry — measuring their ability to translate architectural reference material into parametric CAD code. The benchmark highlights that while basic OpenSCAD syntax is easy for current LLMs, complex 3D architectural modeling remains a demanding test of spatial reasoning capabilities.
