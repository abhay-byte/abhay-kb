# Pyodide 314.0: Python Packages Can Now Publish WebAssembly Wheels Directly to PyPI

> Originally published on Pyodide Blog — June 13, 2026

![Cover](https://placehold.co/800x400/1a1a2e/00d4ff?text=Pyodide+314+WebAssembly+PyPI)

## Summary

Pyodide 314.0 ships with PEP 783 accepted, enabling Python package maintainers to build and publish WebAssembly wheels directly to PyPI — just like native wheels for Linux, macOS, or Windows. This eliminates the massive maintainer bottleneck of having the Pyodide team manually build and host 300+ packages. The release also adopts a new Python-version-based versioning scheme (314.x corresponds to Python 3.14) and restores previously unvendored standard libraries like sqlite3, ssl, and lzma.
