# Backpressure Is All You Need
> Originally published on lucasfcosta.com — May 31, 2026

![Cover](https://placehold.co/800x400/1a1a2e/00d4ff?text=Backpressure+Is+All+You+Need)

## Summary

Lucas Costa argues that the key to safe and effective AI coding agents lies in applying backpressure principles from systems engineering — automated tests, type systems, linters, and CI pipelines act as guardrails that let agents iterate autonomously while humans focus on higher-level design decisions. The post introduces an `npx @lucasfcosta/backpressured` CLI tool that implements this approach by running automated checks between agent iterations, creating a validation loop where the machine refuses bad work before it reaches a human reviewer.
