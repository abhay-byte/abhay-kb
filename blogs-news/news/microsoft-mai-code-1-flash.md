## Summary

Microsoft unveiled MAI-Code-1-Flash, a new coding model trained directly with GitHub Copilot production harnesses rather than optimized for isolated benchmarks. The model outperforms Claude Haiku 4.5 across all core coding benchmarks, with a +16-point lead on SWE-Bench Pro (51.2% vs 35.2%), while solving harder problems with up to 60% fewer tokens through adaptive solution length control — making interactive coding workflows smoother and more cost-effective.
