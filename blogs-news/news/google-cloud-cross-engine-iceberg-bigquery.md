# Google Cloud Introduces Cross-Engine Iceberg Support in BigQuery
> Originally published on InfoQ — May 22, 2026

![Cover](https://placehold.co/800x400/1a1a2e/00d4ff?text=Google+Cloud+Iceberg)

## Summary

Google announced a preview of the serverless Iceberg REST catalog in BigQuery, letting teams create, update, and query the same Apache Iceberg tables across engines like Spark, Flink, and Trino without duplicating data. The preview also introduces managed support for metadata, table maintenance, and synchronization tasks commonly handled manually in Iceberg deployments, as part of Google's push toward a cross-cloud lakehouse for the agentic era.
